## 2. Forum and group answers (Facebook groups, LinkedIn, Reddit, Quora)

Answer the question first. Mention Zennly once, and only when it fits.

**"Which software for salon/spa bookings in Nepal?"**
> If you run more than one branch, look for software that books the staff member, the room and the time together, so double-bookings can't happen, and that makes discounts need a manager's approval. We built Zennly (zennly.io) for this and it runs a four-branch spa in Kathmandu. This checklist covers what to ask any vendor: [link to /blog/how-to-choose-booking-software-nepal/].

**"How do I stop staff giving unauthorised discounts?"**
> Make discounts a request, not a button: staff enter the percentage, a manager approves, and the booking keeps the record. More here: [link to /blog/discount-leakage/].

**"Should I take bookings on WhatsApp?"**
> It works for a few bookings a day, then breaks: no clash checks, no payment record, no audit trail. Some thoughts: [link to /blog/stop-taking-bookings-on-whatsapp-nepal/].
